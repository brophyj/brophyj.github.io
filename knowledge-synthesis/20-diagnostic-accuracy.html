Learning objectives

By the end of this chapter you should be able to:

  • explain why sensitivity and specificity must be analysed together, and how the threshold of a test trades one for the other;
  • move from a pooled sensitivity and specificity to likelihood ratios and post-test probabilities, and explain why predictive values should not be pooled;
  • assess diagnostic accuracy studies with QUADAS-2, and recognise threshold, spectrum and verification effects as sources of heterogeneity;
  • fit the bivariate random-effects model, draw the summary ROC curve with its confidence and prediction regions, convert to HSROC parameters, and add a covariate;
  • explain how GRADE treats diagnostic evidence, and why accuracy alone does not justify a recommendation;
  • appraise and pool external validations of a prediction model, using CHARMS and PROBAST, and pool C-statistics on the logit scale.

R packages: dplyr, tidyr, purrr, ggplot2, metafor, mada, ellipse, knitr; brms for code shown but not run here.

A review of an intervention asks whether a treatment works, and answers with one effect measure. A review of a diagnostic test asks how well the test separates people who have the target condition from those who do not. That needs two numbers, sensitivity and specificity, which are not independent: every test that produces a measurement must be turned into “positive” or “negative” at some threshold, and moving the threshold trades one for the other. This chapter develops the methods for diagnostic test accuracy (DTA) reviews, using high-sensitivity cardiac troponin (hs-cTn) to rule out acute myocardial infarction (MI) as the running example, and then turns to reviews of prediction models, which raise related problems.

20.1 The threshold problem

Code 
set.seed(42)
trop_d  <- rlnorm(1000, 3.0, 0.6)          # MI
trop_nd <- rlnorm(1000, 1.8, 0.5)          # no MI
ops <- tibble::tibble(t = c(5, 14, 40)) |>
  mutate(sens = map_dbl(t, \(x) mean(trop_d >= x)), fpr = map_dbl(t, \(x) mean(trop_nd >= x)),
         lab = sprintf("%g ng/L\nsens %.2f, spec %.2f", t, sens, 1 - fpr))
roc <- tibble::tibble(t = sort(unique(c(0, trop_d, trop_nd, Inf)))) |>
  mutate(sens = map_dbl(t, \(x) mean(trop_d >= x)), fpr = map_dbl(t, \(x) mean(trop_nd >= x)))
p1 <- tibble::tibble(trop = c(trop_d, trop_nd), group = rep(c("MI", "No MI"), each = 1000)) |>
  ggplot(aes(trop, fill = group)) +
  geom_histogram(bins = 60, alpha = 0.6, position = "identity") +
  geom_vline(xintercept = ops$t, linetype = c(2, 1, 3)) +
  scale_x_continuous(limits = c(0, 120)) +
  scale_fill_manual(values = c(MI = "#B22222", `No MI` = "#041E42"), name = NULL) +
  labs(x = "Troponin (ng/L)", y = "Patients") + theme(legend.position = "top")
p2 <- ggplot(roc, aes(fpr, sens)) +
  geom_abline(linetype = 2, colour = "grey60") +
  geom_path(colour = "#041E42", linewidth = 1) +
  geom_point(data = ops, colour = c("#2E7D32", "#E69F00", "#B22222"), size = 3) +
  geom_text(data = ops, aes(label = lab), hjust = -0.1, vjust = 1, size = 3, lineheight = 0.9) +
  coord_equal(xlim = c(0, 1), ylim = c(0, 1)) +
  labs(x = "1 − specificity (false-positive rate)", y = "Sensitivity")
patchwork::wrap_plots(p1, p2)

A low threshold detects almost every MI but labels many patients without MI as positive; a high threshold does the reverse. Studies that use different thresholds report different pairs of sensitivity and specificity for the same test. A review that pools sensitivities and specificities separately averages operating points that no study used, and finds “heterogeneity” that is largely the threshold.

20.2 From the 2×2 table to clinical decisions

Each study contributes a 2×2 table of test result against the reference standard: true positives (TP), false negatives (FN), false positives (FP) and true negatives (TN).

Likelihood ratios link a test result to a patient. On the odds scale, Bayes’ theorem is a multiplication: post-test odds = pre-test odds × LR.

Code 
post <- \(p, lr) { o <- p / (1 - p) * lr; o / (1 + o) }
lr_pos <- 0.98 / 0.25; lr_neg <- 0.02 / 0.75
tibble::tibble(`Pre-test probability` = c(0.05, 0.15, 0.40)) |>
  mutate(`After a positive test` = post(`Pre-test probability`, lr_pos),
         `After a negative test` = post(`Pre-test probability`, lr_neg),
         across(everything(), \(x) sprintf("%.1f%%", 100 * x))) |>
  kable(align = "ccc")

With LR− = 0.027, a negative test lowers a 15% pre-test probability to 0.5%, low enough for a rule-out strategy; with LR+ = 3.9, a positive test raises it only to 41%. A test can be excellent for ruling out and poor for ruling in. Predictive values change with prevalence, so a review should pool sensitivity and specificity (or likelihood ratios) and apply them to the prevalence of the target setting.

20.3 Risk of bias: QUADAS-2

QUADAS-2 assesses diagnostic accuracy studies in four domains, each with signalling questions and a judgement of low, high or unclear risk of bias; the first three also have a judgement of applicability to the review question (1). The domains are not added into a score.

Two designs are especially misleading. A case-control (“two-gate”) design compares clearly diseased patients with healthy volunteers and exaggerates accuracy (Section 20.5). Partial or differential verification, in which not everyone receives the same reference standard, biases sensitivity and specificity in predictable directions:

Code 
tp <- 135; fn <- 15; fp <- 170; tn <- 680; v <- 0.25
tibble::tibble(Verification = c("Full", "Partial: unverified patients excluded",
                                "Differential: unverified negatives assumed MI-free"),
               TP = tp, FN = c(fn, v * fn, v * fn), FP = fp, TN = c(tn, v * tn, tn + (1 - v) * fn)) |>
  mutate(Sensitivity = TP / (TP + FN), Specificity = TN / (TN + FP)) |>
  kable(digits = 2, align = "lcccccc")

Both shortcuts inflate sensitivity; partial verification also deflates specificity. When verification depended only on the test result, the bias can be corrected (2).

20.4 The bivariate model

Each study gives two correlated estimates. The bivariate random-effects model treats each study’s logit sensitivity and logit false-positive rate (FPR = 1 − specificity) as drawn from a bivariate normal distribution, with within-study binomial variation (3):

\[\begin{pmatrix} \text{logit sens}_i \\ \text{logit FPR}_i \end{pmatrix} \sim N\left(\begin{pmatrix} \mu_{sens} \\ \mu_{FPR} \end{pmatrix}, \begin{pmatrix} \sigma_{sens}^2 & \rho\,\sigma_{sens}\sigma_{FPR} \\ \rho\,\sigma_{sens}\sigma_{FPR} & \sigma_{FPR}^2 \end{pmatrix}\right).\]

Five parameters: two means (the summary operating point), two between-study SDs and a correlation. A positive correlation between logit sensitivity and logit FPR is the threshold effect: studies with a low threshold have high sensitivity and a high FPR.

To see what the model recovers, we simulate 14 studies of hs-cTn, each with 400 to 2500 emergency department patients and an MI prevalence of 8% to 20%, using thresholds of 3, 5, 7 or 9 ng/L. At 5 ng/L the true sensitivity is 0.97 and the true FPR 0.21; each 1 ng/L increase in threshold lowers logit sensitivity by 0.30 and logit FPR by 0.18; and studies differ randomly beyond that.

Code 
set.seed(2026)
k <- 14
cut  <- sample(c(3, 5, 7, 9), k, replace = TRUE)
n    <- round(runif(k, 400, 2500)); prev <- runif(k, 0.08, 0.20)
u    <- MASS::mvrnorm(k, c(0, 0), matrix(c(0.30, 0.05, 0.05, 0.12), 2))
lsens <- qlogis(0.97) - 0.30 * (cut - 5) + u[, 1]
lfpr  <- qlogis(0.21) - 0.18 * (cut - 5) + u[, 2]
dis <- rbinom(k, n, prev)
TP <- rbinom(k, dis, plogis(lsens)); FN <- dis - TP
FP <- rbinom(k, n - dis, plogis(lfpr)); TN <- n - dis - FP
dta <- data.frame(study = paste0("S", 1:k), cut, TP, FN, FP, TN)
fit <- reitsma(dta)                                    # bivariate model, REML
sm  <- summary(fit)$coefficients
tibble::tibble(Parameter = c("Sensitivity", "Specificity", "SD logit sensitivity", "SD logit FPR", "Correlation ρ"),
               Estimate = c(sprintf("%.3f (%.3f to %.3f)", sm[3, 1], sm[3, 5], sm[3, 6]),
                            sprintf("%.3f (%.3f to %.3f)", 1 - sm[4, 1], 1 - sm[4, 6], 1 - sm[4, 5]),
                            sprintf("%.2f", sqrt(fit$Psi[1, 1])), sprintf("%.2f", sqrt(fit$Psi[2, 2])),
                            sprintf("%.2f", cov2cor(fit$Psi)[1, 2]))) |>
  kable(align = "lc")
Parameter Estimate
Sensitivity 0.949 (0.918 to 0.969)
Specificity 0.822 (0.788 to 0.852)
SD logit sensitivity 0.83
SD logit FPR 0.40
Correlation ρ 0.57

The summary point averages studies that used thresholds from 3 to 9 ng/L, a threshold nobody uses. The positive correlation is the threshold effect; the between-study SDs include it.

20.4.1 The summary ROC curve

Code 
mu  <- coef(fit)[1, ]; V <- vcov(fit); Psi <- fit$Psi
sw  <- \(m) m[2:1, 2:1]                                # order (FPR, sens)
conf <- as.data.frame(plogis(ellipse::ellipse(sw(V), centre = mu[2:1], level = 0.95)))
pred <- as.data.frame(plogis(ellipse::ellipse(sw(Psi + V), centre = mu[2:1], level = 0.95)))
names(conf) <- names(pred) <- c("fpr", "sens")
srocc <- as.data.frame(sroc(fit, fpr = seq(0.01, 0.6, length.out = 300))); names(srocc) <- c("fpr", "sens")
ggplot() +
  geom_polygon(data = pred, aes(fpr, sens), fill = NA, colour = "#041E42", linetype = 2) +
  geom_polygon(data = conf, aes(fpr, sens), fill = "#041E42", alpha = 0.25) +
  geom_line(data = srocc, aes(fpr, sens), colour = "#B22222", linewidth = 1.1) +
  geom_point(data = dta, aes(FP / (FP + TN), TP / (TP + FN), colour = factor(cut)), size = 2.5) +
  annotate("point", x = plogis(mu[2]), y = plogis(mu[1]), shape = 18, size = 5, colour = "#B22222") +
  scale_colour_manual(values = c("#0072B2", "#009E73", "#E69F00", "#B22222"), name = "Threshold (ng/L)") +
  coord_cartesian(xlim = c(0, 0.6), ylim = c(0.5, 1)) +
  labs(x = "1 − specificity", y = "Sensitivity")

The summary ROC (SROC) curve shows the trade-off between sensitivity and FPR as the threshold changes; its area is 0.93. The confidence region shows how well the average operating point is known; the prediction region, which adds between-study variation, shows where a new study is likely to fall, and is much larger. Studies spread along the curve, ordered by their thresholds.

20.4.2 HSROC parameters

The hierarchical summary ROC (HSROC) model describes the same studies as points on one curve: each study has an accuracy (Λ, the log DOR in the middle of the curve), a threshold or positivity parameter (Θ), and the curve has a shape (β, which allows the DOR to change along the curve) (4). Without covariates, the bivariate and HSROC models are the same model in different parameterisations, and the HSROC parameters are functions of the bivariate ones (5):

Code 
sA <- sqrt(Psi[1, 1]); sB <- sqrt(Psi[2, 2]); sAB <- -Psi[1, 2]   # A = sensitivity, B = specificity
muA <- mu[[1]]; muB <- -mu[[2]]; r <- sB / sA
hs <- c(beta = log(r), Lambda = sqrt(r) * muA + sqrt(1 / r) * muB,
        Theta = (sqrt(r) * muA - sqrt(1 / r) * muB) / 2,
        sd_accuracy = sqrt(2 * (sA * sB + sAB)), sd_threshold = sqrt((sA * sB - sAB) / 2))
round(hs, 2)
        beta       Lambda        Theta  sd_accuracy sd_threshold 
       -0.73         4.24        -0.08         0.54         0.51

Λ = 4.24 corresponds to a DOR of about 69 in the middle of the curve. β = -0.73 is away from 0, so the DOR changes with the threshold, and the SD of accuracy is similar to the SD of threshold: not all of the heterogeneity is threshold variation.

20.4.3 What the summary means clinically

Code 
s_sum <- plogis(mu[[1]]); f_sum <- plogis(mu[[2]])
lrn <- (1 - s_sum) / (1 - f_sum)

At the summary point, LR− = 0.062, and a negative test lowers a 15% pre-test probability to 1.1%. Safe discharge after a rule-out test usually requires a miss rate below about 1%, so the average operating point is not good enough on its own. But the average is the wrong question: the rule-out decision needs accuracy at the low threshold actually used, which the next section estimates.

In the real evidence, all studies used one rule. A collaborative meta-analysis of 11 cohorts and 9241 patients evaluated a single hs-cTnT below the limit of detection (5 ng/L) combined with a non-ischaemic ECG: 30.6% of patients were classified as low risk, 0.5% of them had an MI, and the pooled sensitivity was 98.7% (95% CI 96.6% to 99.5%) (6). With one threshold there is no threshold effect to model, which is why the simulation is used here to illustrate the bivariate model.

20.5 Heterogeneity in diagnostic accuracy

Three sources of heterogeneity are specific to diagnostic studies.

  • Threshold variation, already seen. Report the SROC curve, and accuracy at clinically relevant thresholds.
  • Spectrum. Sensitivity is higher in patients with severe or established disease than in patients with early or mild disease; specificity is higher in healthy volunteers than in symptomatic patients without the disease. A case-control study that enrols both extremes overestimates both. The same assay at the same threshold has different accuracy in a tertiary centre and in an emergency department.
  • Verification (Section 20.3).

Adding a covariate to the bivariate model gives a bivariate meta-regression. With the threshold as covariate:

Code 
fit_cut <- reitsma(dta, formula = cbind(tsens, tfpr) ~ cut)
b <- coef(fit_cut)
tibble::tibble(`Threshold (ng/L)` = c(3, 5, 7, 9)) |>
  mutate(Sensitivity = plogis(b[1, 1] + b[2, 1] * `Threshold (ng/L)`),
         Specificity = 1 - plogis(b[1, 2] + b[2, 2] * `Threshold (ng/L)`)) |>
  kable(digits = 3, align = "ccc")
Threshold (ng/L) Sensitivity Specificity
3 0.978 0.764
5 0.962 0.806
7 0.934 0.843
9 0.889 0.874

The between-study SD of logit sensitivity falls from 0.83 to 0.54 once the threshold is in the model: much of the heterogeneity was the threshold. At 3 ng/L, sensitivity is about 0.978, which is what a rule-out decision needs. The usual cautions of meta-regression apply (Section 10.1). Comparing two tests is best done with studies that applied both tests to the same patients; comparisons across separate sets of studies are confounded by everything else that differs (7).

20.6 GRADE for diagnostic evidence

GRADE rates the certainty of accuracy estimates with the usual domains (risk of bias judged with QUADAS-2, indirectness, inconsistency, imprecision and publication bias). Cross-sectional accuracy studies of consecutive patients with full verification start at high certainty for accuracy (8). Imprecision is judged against the decision: for rule-out, whether the lower limit of sensitivity still gives an acceptable miss rate.

Accuracy is only the first link of a chain. A test improves outcomes only if its result changes management and the change helps patients. That needs evidence on test-and-treat strategies. In the High-STEACS stepped-wedge cluster trial, ten Scottish hospitals introduced a high-sensitivity troponin I assay in random order (48,282 patients). The assay reclassified 1771 patients as having myocardial injury or infarction, but among them MI or cardiovascular death at one year was not reduced, 15% before and 12% after implementation, adjusted OR 1.10 (95% CI 0.75 to 1.61) (9). More accurate diagnosis does not automatically mean better outcomes; its main value may lie elsewhere, for example in faster safe discharge, which needs its own evaluation.

20.7 Reviews of prediction models

A prediction model estimates an individual’s probability of a diagnosis or a future outcome from several predictors, for example the 10-year risk of a cardiovascular event from age, sex, smoking, blood pressure, cholesterol and diabetes. Reviews of prediction models face their own versions of the problems above.

  • CHARMS structures data extraction: data source, participants, outcome, predictors, sample size and events, missing data, model development, and performance measures (10).
  • PROBAST assesses risk of bias in four domains (participants, predictors, outcome, analysis); the analysis domain is the one most often at high risk, through too few events per predictor, no internal validation, or no assessment of calibration (11).
  • TRIPOD is a reporting guideline for primary studies, not a quality tool; reviews are reported with TRIPOD-SRMA (12).

Performance has two parts. Discrimination, usually the C-statistic (the probability that a randomly chosen person with the outcome has a higher predicted risk than one without), measures ranking. Calibration, measured by the observed-to-expected (O:E) ratio and the calibration slope, measures whether predicted risks are right. A model can discriminate well and still predict risks that are systematically too high, which is what matters for decisions based on absolute risk (13).

Apparent performance, measured in the data used to develop a model, is optimistic. Internal validation (bootstrapping or cross-validation) estimates the optimism; only external validation in new patients shows whether a model transports (14). A meta-analysis of performance should pool external validations of one model and never mix in apparent performance from development studies.

20.7.1 Pooling C-statistics

Nine hypothetical external validations of one cardiovascular risk model report C-statistics in hospital clinics, community practices and primary care. The C-statistic is a bounded probability, so it is pooled on the logit scale, with its standard error converted by the delta method, and with random effects, because performance depends on case-mix and setting (15).

Code 
val <- tibble::tribble(~study, ~auc, ~se, ~setting,
  "Cohort A", 0.77, 0.02, "Hospital", "Cohort B", 0.70, 0.03, "Community", "Cohort C", 0.80, 0.02, "Hospital",
  "Cohort D", 0.70, 0.03, "Primary care", "Cohort E", 0.67, 0.03, "Community", "Cohort F", 0.75, 0.02, "Hospital",
  "Cohort G", 0.73, 0.03, "Community", "Cohort H", 0.68, 0.02, "Primary care", "Cohort I", 0.79, 0.02, "Hospital") |>
  mutate(yi = qlogis(auc), sei = se / (auc * (1 - auc)))      # logit C and delta-method SE
res <- rma(yi, sei = sei, data = val, method = "REML", test = "knha", slab = study)
pr  <- predict(res, transf = plogis)
set_col <- c(Hospital = "#041E42", Community = "#2E7D32", `Primary care` = "#B22222")
metafor::forest(res, transf = plogis, refline = NA, addpred = TRUE, at = seq(0.5, 0.9, 0.1),
                colout = set_col[val$setting], ilab = val$setting, ilab.lab = "Setting",
                header = c("Validation", "C [95% CI]"), mlab = "Random effects (REML, HKSJ)", xlab = "C-statistic")

The pooled C-statistic is 0.74 (95% CI 0.70 to 0.77), adequate on average, but the prediction interval, 0.62 to 0.83, shows that in a new setting the model may discriminate well or barely adequately. Validations in hospitals do better than those in community and primary care, consistent with more heterogeneous case-mix in hospital populations (in these simulated data). Calibration is not shown because, as is common, it was not reported consistently; it usually varies far more between settings than discrimination, and a model should be recalibrated locally before use.

With few validations, τ is poorly estimated, and a Bayesian random-effects model with a weakly informative prior on τ (for example half-Student-t with scale 0.5 on the logit C scale) gives more honest prediction intervals and direct probabilities such as P(C > 0.70 in a new setting) (15):

Code 
library(brms)
fit_b <- brm(yi | se(sei) ~ 1 + (1 | study), data = val, seed = 629,
             prior = c(prior(normal(0, 2), class = Intercept), prior(student_t(3, 0, 0.5), class = sd)))
d <- as_draws_df(fit_b)
c_new <- plogis(d$b_Intercept + rnorm(nrow(d), 0, d$sd_study__Intercept))
quantile(c_new, c(0.025, 0.975)); mean(c_new > 0.70)

Key points

  1. Sensitivity and specificity are paired and depend on the threshold; analyse them jointly with the bivariate (or equivalent HSROC) model.
  2. Pool sensitivity and specificity, not predictive values; translate them with likelihood ratios to the pre-test probability of the target setting.
  3. Assess studies with QUADAS-2; case-control designs and partial or differential verification bias accuracy.
  4. Report the summary point with its confidence and prediction regions and the SROC curve, and accuracy at the threshold used in practice.
  5. Threshold, spectrum and verification explain much diagnostic heterogeneity; bivariate meta-regression can quantify the threshold effect.
  6. Accuracy does not guarantee better outcomes; recommendations need evidence about test-and-treat strategies.
  7. For prediction models, pool external validations only, on the logit (C-statistic) or log (O:E) scale, with random effects and prediction intervals; calibration matters as much as discrimination.
